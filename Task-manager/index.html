About TaskManager

TaskManager is a simple task management application designed to help users organize their daily work.

Users can create tasks, set priorities, choose due dates, complete tasks and remove tasks.

Features

  • Create tasks
  • Edit tasks
  • Delete tasks
  • Mark tasks as completed
  • Set task priority
  • Set due dates
  • User authentication
  • Database storage
